# MinNote v0.0.9.11 — Tối Giản Luồng JSON, Hợp Nhất Studio TikZ Tĩnh & Động, Nâng Cấp Prompt AI 20 Công Cụ

- **Tối Giản Hóa Tab `📦 Nạp / Lưu JSON` (Tách Bạch Hoàn Toàn Khỏi TikZ)**:
  - Đưa luồng JSON về **1 định dạng chuẩn duy nhất `mn-geo-motion/2.0` thuần khiết** (`📂 Mở tệp .json`, `💾 Lưu bảng ra .json`, `📋 Chép JSON từ bảng`), tự động loại bỏ phần mã TikZ đính kèm dư thừa để tệp JSON luôn gọn sạch.
  - Bổ sung thẻ **Bước 1** trực quan với nút **`📋 Chép Prompt Dựng Hình Chi Tiết`** và **`👁 Xem nội dung Prompt`** ngay trong hộp thoại, kèm bộ nhận diện thông minh cảnh báo thân thiện nếu người dùng dán nhầm nội dung Prompt thay vì kết quả JSON.
- **Hợp Nhất Cửa Sổ `📐 Xuất TikZ`: Chuyển Đổi Tức Thì Giữa `TikZ Tĩnh (Chuẩn SGK)` & `TikZ Chuyển Động (BetaTikz)`**:
  - Tích hợp 2 tab trực tiếp ngay trên thanh tiêu đề của cửa sổ **Xuất TikZ**: bấm **`📐 TikZ Tĩnh (Chuẩn SGK)`** để lấy mã TikZ lưới nguyên/nửa nguyên đạt 12/12 quy chuẩn MEA v5, hoặc bấm **`🎬 TikZ Chuyển Động (BetaTikz)`** để đổi ngay tại chỗ sang mã `out_tikz (\t ∈ [0, 1])` / `LaTeX animateinline` kèm trục thời gian diễn hoạt trực quan và xuất gói `.betatikz.json`.
  - Tách thanh công cụ nhanh trên khung **Diễn Hoạt** thành 2 nút rõ ràng: **`📐 TikZ Động`** và **`📦 JSON`**.
- **Nâng Cấp Đại Từ Điển Prompt Chuẩn 20 Công Cụ Dựng Hình MinNote (`prompts/PROMPT_CHUAN_DUNG_HINH_MINNOTE.md`)**:
  - Bổ sung tệp Prompt chuẩn 1-click tự chứa đầy đủ cú pháp JSON hợp lệ cho **toàn bộ 20 công cụ dựng hình gốc** (`point_free` đến `tick_mark`), hướng dẫn chi tiết từng bước cho **6 dạng toán hình học phẳng 2D & không gian 3D trọng tâm**, bảng hiệu ứng chuyển động từng nét và mẫu JSON `mn-geo-motion/2.0` hoàn chỉnh.
