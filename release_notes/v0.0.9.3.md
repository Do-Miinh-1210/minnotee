## MinNote v0.0.9.3

Bản cập nhật mở rộng toàn bộ danh sách Model AI cho mọi nhà cung cấp và khắc phục triệt để lỗi quá thời gian chờ khi AI đọc ảnh đề để dựng hình:

- **Mở rộng & tự động cập nhật Model AI cho cả 6 nhà cung cấp**:
  - Cập nhật danh sách chuẩn đầy đủ: **Antigravity** (**27 model** từ `agy CLI`, bao gồm đủ các dòng `gemini-3.8-flash-*`, `gemini-4-neon-*`, `gemini-4-carbon-*`, `gemini-4-argon-*`, `gemini-4-hydrogen-*`, `gemini-pro-orchestrator*`, `claude-sonnet-5-5-*`, `claude-opus-5-5-*`, `gpt-oss-120b-medium`), **Google Gemini** (11 model API chuẩn), **9Router** (19 model mặc định + nạp trực tiếp từ cổng `20128`), **Anthropic Claude** (12 model), **OpenAI GPT** (11 model gồm `gpt-5.2`, `gpt-5`, `gpt-4.1*`, `o3`, `o4-mini`), **DeepSeek** (3 model).
  - Bật nút **🔄 Làm mới model** + **lưu cache model trực tiếp (15 phút)** cho tất cả nhà cung cấp, thêm badge đếm model và ô **Lọc nhanh model** ngay trong **Cài đặt → API Key & MEA**.
- **Khắc phục lỗi `Yêu cầu MEA_AI_EXECUTE quá thời gian chờ.` & đọc ảnh dựng hình**:
  - Sửa cấu hình gọi `Antigravity CLI` (`--dangerously-skip-permissions`, `--disable-slash-commands`, `--add-dir`), nâng giới hạn chờ C#/JS lên `255s`/`260s`, hỗ trợ fallback đọc stream phản hồi và chuẩn hóa định dạng ảnh đầu vào (tự đặt nền trắng cho ảnh PNG trong suốt, giới hạn kích thước tối đa `1600px`).
  - Tinh gọn prompt dựng hình để xử lý nhanh cả ảnh đề chữ, ảnh bảng Đúng/Sai và ảnh hình vẽ sẵn có; đồng thời nâng cấp tương thích Gemini (bỏ phần `thought`), OpenAI `o1`/`o3`/`o4`/`gpt-5` (`max_completion_tokens`) và thông báo rõ cho DeepSeek text-only.
- **Nâng cấp hộp thoại `AI Dựng Hình Từng Nét`**:
  - Bổ sung thanh chọn nhanh Model AI ngay trong cửa sổ (kèm gợi ý tốc độ), bộ đếm giây tiến trình theo thời gian thực, sửa nút **🔑 API Key** mở thẳng tab **Cài đặt → API Key & MEA** và nâng `z-index` để không bị che khuất.
