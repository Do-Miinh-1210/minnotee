## MinNote v0.0.9.12

Bản cập nhật nâng cấp bộ làm sạch dữ liệu cho tab **📦 Nạp / Lưu JSON** (`mn-geo-motion/2.0`) và tối ưu Prompt dựng hình cho AI ngoài:

- **Tự động làm sạch JSON bị thoát định dạng Markdown / HTML khi sao chép từ AI ngoài**: tự nhận diện và gỡ bỏ dấu `\` ngắt dòng cuối dòng (`{\`), ký tự khoảng trắng HTML (`&#x20;`, `&nbsp;`, `&#160;`, `&#32;`), ký tự thoát thừa (`\_`, `\'`, `\[`, `\]`, `\{`, `\}`, `\"`), ký tự trắng ẩn (BOM / zero-width) và dấu ngoặc kép thừa bọc ngoài khối JSON ở cả **AI Dựng Hình Từng Nét** lẫn **Motion Bridge** — dán vào là hợp lệ và dựng hình ngay lập tức.
- **Tối ưu Prompt Dựng Hình Chi Tiết (Mẫu 3 & Phần 5)**: bổ sung yêu cầu bắt buộc xuất JSON chuẩn trong code block ```` ```json ... ``` ```` (tránh escape Markdown) và thêm hệ tọa độ chuẩn SGK cho hình hộp `ABCD.A'B'C'D'`.
- **Sửa lỗi nút "Chèn tĩnh" trên tab Nạp / Lưu JSON**: khi chọn **Chèn tĩnh**, hình vẽ hiển thị trọn vẹn ngay lập tức trên bảng (không còn bị ẩn ở trạng thái diễn hoạt `0/N`) đồng thời vẫn lưu sẵn kịch bản để chạy lại bất cứ lúc nào bằng nút **Dựng lại hình**.
